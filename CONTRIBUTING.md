# Contributing

This public project uses MIT for original project source and documentation. Contributions must have a clear source and compatible terms; preserve all applicable notices. See LICENSE, THIRD_PARTY_NOTICES.md and docs/license-closure.md.

Use a separate environment and temporary data/cache roots. Never commit research history, personal captures, secrets, model weights or binaries. Keep evidence classifications, source selection, query reservations, cache admission, free-only fallback and semantic-review gates intact. New behavior must not reinterpret synthetic tests as source/media acceptance.

Run the checks in docs/testing.md. Changes should include the concrete behavior, relevant verification and any remaining limits. No publishing, GitHub push or paid-provider call is part of the test suite.
